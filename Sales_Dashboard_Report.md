# Sales Dashboard Project Report

## 1. Introduction

This project presents an interactive sales dashboard built using HTML, CSS, and JavaScript.

## 2. Objectives

* Analyze total sales and profit.
* Compare regional sales performance.
* Explore monthly sales trends.
* Compare product categories.
* Display interactive business KPIs.

## 3. Tools Used

* HTML
* CSS
* JavaScript
* GitHub
* GitHub Pages

## 4. Dataset

The project uses 18 sample sales records covering January to June 2026. The dataset includes order date, product, category, region, sales, profit, and quantity.

## 5. Key Performance Indicators

* Total Sales
* Total Profit
* Units Sold
* Profit Margin

Profit Margin = (Total Profit / Total Sales) × 100

## 6. Visualizations

* Sales by Region
* Monthly Sales Trend
* Sales by Category

## 7. Interactive Features

Users can filter the dashboard by region and month. KPI values and charts update when filters change.

## 8. Testing

The live dashboard was checked for KPI cards, regional sales, monthly trends, category charts, and interactive filters.

## 9. Limitations

The dashboard uses a small sample dataset for demonstration and is built as a web dashboard, not an Excel or Power BI file.

## 10. Conclusion

This project demonstrates basic sales analysis, KPI calculations, data visualization, and deployment using GitHub Pages.
